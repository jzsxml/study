# 小茉莉知识学习站 · 人教版 1-6 年级

线上地址：<https://study.apixml.top/>

一个纯前端（无需安装、无需联网）的小学学习工具，覆盖六大部分：

1. **英文知识**：人教 PEP（三年级起点）8 册，454 个单元核心词汇（音标 + 中文释义，点击即读）、64 组必会句型（每册 8 组）、56 个语法知识点（每册 7 个）；支持按册浏览、跨册搜索、整单元连读、语速调节、自测模式。
2. **语文知识**：统编版 1-6 年级上下 12 册，36 条语文知识与考点（按低 1-2 / 中 3-4 / 高 5-6 年级分段：拼音字词、查字典、词语积累、句式标点、修辞、阅读、写作、名著与传统文化），595 个精选生字（拼音 + 组词，点击朗读），95 篇课文必背古诗文（原文 + 朗读 + 背诵遮盖模式）。
3. **数学知识点与口算**：人教版 1-6 年级上下 12 册，按单元整理的概念、公式、易错点；另有按年级上下册分册整理的「年级考点梳理」（53 条），选册后自动匹配对应学期；口算练习按年级随机出题、即时判分。
4. **作文宝典**：1-6 年级 110 个好词、36 条金句、18 段好段、12 篇满分范文（含点评）、24 条写作技法，支持朗读。
5. **道德与法治**：人教（统编）版 1-6 年级上下 12 册，95 条行为规范/安全自护/规则法治/家国情怀要点 + 48 道情景判断题（即时判分并给解析）。
6. **科学**：小学科学 1-6 年级上下 12 册，76 条生命科学/物质科学/地球与宇宙/技术与工程知识点（含小实验建议）+ 36 道科学小问答（选择即判分）。

## 使用方法

直接双击 `index.html`，用 Chrome / Edge 打开即可（推荐 Edge 或 Chrome：Windows 系统自带中英文语音，发音最稳定）。

> 发音由浏览器内置的语音合成（Web Speech API）实时生成，不需要下载任何音频文件，离线也能用。

## 功能

| 模块 | 功能 |
| --- | --- |
| 英文知识 | 分「单词 / 句型 / 语法」三类切换；按册浏览 8 册内容；单词点击发音，「连读本单元」顺序朗读并高亮；句型、语法卡片可朗读英文例句；搜索时跨全部 8 册检索；自测模式隐藏单词中文 |
| 语文知识 | 按册展示低 / 中 / 高年级知识与考点（类别标签 + 易错提示，可整条朗读）；跨册搜索知识、生字、诗文 |
| 语文生字 | 按册浏览；点击生字朗读「字 + 组词」；搜索汉字、拼音、组词；自测模式隐藏拼音 |
| 必背诗文 | 按册浏览；整篇朗读并逐行高亮；背诵模式下遮盖原文，点击「显示原文」核对；带易错字、读音、考点提示 |
| 数学知识 | 按册浏览 12 册知识点（数与代数 / 图形与几何 / 统计与概率 / 综合与实践），含公式与易错提示；顶部「年级考点梳理」按年级上下册自动匹配；支持跨册搜索 |
| 口算练习 | 选年级（1-6）随机出题，题量 5/10/20；输入整数、小数、分数或百分数，回车即判分；实时统计进度、对错与正确率 |
| 作文宝典 | 按年级浏览好词（点击朗读）、金句、好段、满分范文（可整篇朗读并逐段高亮）、写作技法；类别筛选 + 跨年级搜索 |
| 道德与法治 | 按册浏览要点（主题标签 + 「我能做到」行动建议，可整条朗读）；「情景判断」选对/错即时判分并显示解析，实时统计正确率；跨册搜索 |
| 科学 | 按册浏览知识点（领域标签 + 「小实验/小观察」建议，可整条朗读）；「科学小问答」三选一即时判分并给解析；跨册搜索 |
| 通用 | 语速 0.5-1.3 倍调节；「停止」一键中断；自动记忆上次浏览的册和模块；打印友好 |

## 数据说明与扩充

- 英语按教材单元主题整理了各单元**核心必会词**（每单元约 10 词），不是逐页词表；单词用 `w`（单词）、`p`（音标，短语可留空）、`c`（中文）三个字段。
- 语文生字按各册写字表**精选常用字**归类，诗文为各册课文与语文园地中的必背篇目。
- 数学按各册单元主题整理了**知识点、公式与易错点**，不是教材全文；每条形如 `{ cat: '数与代数', t: '标题', lines: ['内容1', '内容2'], tip: '易错提示' }`。
- 作文按年级整理，范文为示范写法（不是教材原文），每篇附点评；数据结构为 `{ t, type, len, body: [段落], review }`。
- 道德与法治按册的主题归纳要点（不逐课照搬教材原文），判断题为常见易错说法；格式为 `{ cat, t, lines, act }` 与 `{ q, a, why }`。
- 科学参照人教/教科版教材的单元主题整理（小学科学各地版本不同，内容以课标核心概念为准）；格式为 `{ cat, t, lines, exp }` 与 `{ q, opts, a, why }`。
- 六处数据都是纯 JS 数据，格式统一，直接照格式增删即可，刷新页面即生效。例如新增一个单词：

```js
{ w: 'apple', p: '/ˈæpl/', c: '苹果' }
```

新增一篇诗文：

```js
{ t: '题目', a: '作者', dyn: '朝代', lines: ['第一行，', '第二行。'], note: '背诵提示（可省略）' }
```

新增一条数学知识点：

```js
{ cat: '图形与几何', t: '圆的周长', lines: ['C = πd = 2πr（π≈3.14）'], tip: '已知直径求周长要乘π' }
```

新增一篇范文：

```js
{ t: '题目', type: '记事', len: 400, body: ['第一段……', '第二段……'], review: '点评：结构清楚，细节生动。' }
```

新增一条道德与法治要点和一道判断题：

```js
{ cat: '安全自护', t: '交通安全', lines: ['过马路走斑马线，不闯红灯。'], act: '我能做到：过马路先看左再看右。' }
{ q: '没有车的时候可以闯红灯。', a: false, why: '规则不是为了应付别人，闯红灯随时可能发生危险。' }
```

新增一条科学知识点和一道选择题：

```js
{ cat: '物质科学', t: '磁铁的磁极', lines: ['同名磁极相互排斥，异名磁极相互吸引。'], exp: '小实验：用两块条形磁铁试试 N 极和 N 极靠近会怎样。' }
{ q: '两块磁铁的 N 极靠近会？', opts: ['相互吸引', '相互排斥', '没有反应'], a: 1, why: '同名磁极相斥，异名磁极相吸。' }
```

## 浏览器兼容

- Chrome / Edge / Safari / Firefox 现代版本均可。
- 若听不到声音：检查系统是否安装对应语言的语音包（Windows：设置 → 时间和语言 → 语言 → 语音），或点击右上角「停止」后重试。
- 页面内 `localStorage` 仅用于记住浏览位置，不收集任何数据。
